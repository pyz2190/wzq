# 五子棋AI程序

## 项目简介

这是一个基于Alpha-Beta剪枝算法的五子棋AI程序，实现了12×12棋盘的对战功能。

## 编译和运行

### 编译
```bash
gcc -o gomoku_ai gomoku_ai.c -lrt -O2 -Wall
```

### 测试
```bash
./test_ai.sh
```

### 运行
```bash
./gomoku_ai
```

程序通过标准输入/输出与评测平台交互。

## 核心特性

### 1. 原创评分体系
- 五连：100,000分
- 活四：20,000分
- 冲四：5,000分
- 活三：3,000分
- 眠三：800分
- 活二：200分
- 眠二：50分
- 单子：10分

### 2. 搜索算法
- **Alpha-Beta剪枝**：减少搜索节点
- **自适应深度**：
  - 开局（<10步）：深度4
  - 中局（10-80步）：深度6
  - 残局（>80步）：深度8
- **启发式排序**：攻防权重11:9
- **候选截断**：每层最多搜索15个候选

### 3. 时间管理
- 单步时限：1900ms（留100ms缓冲）
- 总时限：88000ms（留2秒缓冲）
- 多层超时检查
- 动态时间分配

### 4. 优化技术
- 邻域过滤（3格半径）
- 快速棋型识别
- 立即战术检测（必胜/必防）
- 非对称评估（进攻 vs 防守）

## 算法说明

### Alpha-Beta剪枝原理

Alpha-Beta是极小极大搜索的优化版本：
- Alpha：当前已知的最大下界
- Beta：当前已知的最小上界
- 当 alpha >= beta 时进行剪枝，跳过不必要的搜索

### 启发式排序

对候选走法按优先级排序：
```
priority = attack_score * 11 + defense_score * 9
```

优先搜索高价值走法，提高剪枝效率。

### 自适应深度

根据棋局阶段动态调整：
- 开局：候选多，深度浅，避免超时
- 中局：平衡深度和时间
- 残局：候选少，深度深，追求最优

| 候选数量 | 15个 | 平衡效率和质量 |

## 性能预估

- **时间复杂度**：O(b^d)，实际剪枝后约10-50万节点/步
- **空间复杂度**：< 1MB（远低于350MB限制）
- **单步用时**：平均0.5-1.5秒
- **总用时**：约30-60秒（远低于90秒限制）
